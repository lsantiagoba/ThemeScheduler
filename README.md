# Theme Scheduler

GNOME Shell extension that automatically switches the system color scheme at times you choose.

## Features

- Choose separate start times for the light and dark themes.
- Uses the local system clock and supports schedules that cross midnight.
- Applies schedule changes immediately and checks the current theme automatically.
- Supports GNOME Shell 45, 46, 47, 48, 49, and 50.

## Install

```bash
./install.sh
```

Open the Extensions app, select **Theme Scheduler**, and set the light and dark start times in its preferences.

## Package

```bash
./pack-extension.sh
```

## Uninstall

```bash
./uninstall.sh
```
